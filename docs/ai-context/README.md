# GST AI 上下文入口

本目录是给 Codex/AI 会话使用的短上下文文档。新会话先读这里，再按需读取 `docs/` 和代码。

## 推荐读取顺序

1. `PROJECT.md` — 项目做什么、给谁用、核心模块是什么。
2. `STATUS.md` — 当前开发到了哪一步、下一步优先级、已知风险。
3. `RUNBOOK.md` — 常用运行、构建、测试命令。
4. 需要细节时再读：
   - `docs/OVERVIEW.md` — 功能清单和产品视角。
   - `docs/ARCHITECTURE.md` — 架构、目录、API、数据模型。
   - `docs/TESTING.md` — 测试日志和验证标准。

## 维护规则

- 每个文件保持短小，默认不超过 80 行。
- 项目能力、API、运行方式、测试样例或当前优先级变化时，同步更新对应文件。
- `PROJECT.md` 只写稳定事实；`STATUS.md` 写当前进度；`RUNBOOK.md` 写可执行命令。
- `STATUS.md` 的最近变化只保留最近 5-8 条，旧内容迁移到详细文档或提交记录。
- 不在这里复制长代码、完整 API 文档或长设计说明，只保留新会话必须知道的信息。
