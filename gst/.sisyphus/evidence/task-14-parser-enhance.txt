=== Task: Enhance RawTraceParser for Bug Diagnostic Engine ===

Changes made:
1. raw_trace_parser.go - Enhanced parser with new fields extraction
2. internal/core/bug/testdata/sample_trace.log - 44-line test trace file
3. raw_trace_parser_test.go - 5 new test functions

New regex vars added:
- gcTidRegex: extracts gc=/tid= from lines with [N] prefix
- gcTidNoPrefixRegex: same without prefix
- glSetErrorRegex: extracts gl_error=N from __glSetError lines
- segfaultRegex: detects segments/SIGSEGV/core dumped
- nilPtrRegex: detects ptr=(nil) in params
- ctxMgmtRegex: identifies glXMakeCurrent/glXCreateContextAttribsARB

New functions:
- extractGCTID(line) -> (gcAddr, tid, workLine)
- ensureFrame(frame, frameNum, lineNum)

Parser enhancements:
- GCAddr/TID extracted from (gc=0x..., tid=0x...): prefix on each line
- __glSetError lines -> APILogEntry with IsError=true, ErrorCode="gl_error=0xNNNN"
- Segment fault markers -> APILogEntry with IsError=true, ErrorCode="SIGSEGV"
- ptr=(nil) in params -> HasNilPtr=true on APILogEntry
- glXMakeCurrent/glXCreateContextAttribsARB parsed as normal API calls
- Lines with gc=/tid= prefix are no longer skipped
